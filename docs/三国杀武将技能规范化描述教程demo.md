# 三国杀武将技能规范化描述教程

> 写给民间武将 DIYer：把一段不规范、口语化或写法混乱的技能描述，改成符合官方风格的规范文本。

---

## 一、适用范围与版本约定

- **适用对象**：武将技能描述文本（含"标签+时机+条件+效果"的完整句段），不适用于卡牌描述、FAQ、活动说明。
- **符号约定**：【】=牌名括号；〖〗=技能名括号；（）=补充说明括号；“”=标记名引号。
- **规则编号**：B-xx 基础规范（第二节），A-xx 进阶规范（第三节）。改写时先过基础，再过进阶。
- **凡本教程未覆盖的写法**，按"规则集/wiki描述"处理；仍无依据时，宁可保留原句，不要臆造。

## 二、基础规范

### 2.1 数字与量词

#### 规则 B-01：计数用汉字数字

- **正例**："每个回合结束时，你摸**两张牌**"（〖肆恣〗势钟会）
- **反例**："回复1点体力并摸**2张牌**"（〖怯言〗陆文漪）
- **变量例外**：X、Y 可直接带量词（"X张"）。

#### 规则 B-02：点值用阿拉伯数字

- **正例**："对一名角色造成**1点**火焰伤害"（〖探锋〗势夏侯尚）
- **反例**："造成**一点**火焰伤害"（〖绝殉〗崔芷）

#### 规则 B-03：量词与名词固定搭配

| 对象 | 量词 | 备注 |
|---|---|---|
| 牌 | 张 | "摸X张牌"须带"牌"字 |
| 角色 | 名 | 不用"位/个"+角色 |
| 伤害/体力/上限/护甲/蓄力点 | 点 | 配 B-02 |
| 标记 | **枚** | 无|
| 回合 | 个 | "（一/两/X）个回合" |
| 次数 | 次 | 配 B-01 |

- **正例**："你摸X张牌并展示Y张手牌"（〖幸宠〗滕公主）
- **反例（构造）**："**一位**角色""获得**一个**“死”"（量词错配）

### 2.2 标点与空格

#### 规则 B-04：全角标点，句号收尾

- **正例**："锁定技。①游戏开始时，你获得3枚“毅”标记；…"（〖弘毅〗势陈到）
- **反例**："你选择一项:1.令其弃置等量其他类型的牌"（〖睦阵〗新杀向宠，半角冒号）
- **补充**：不带句号收尾属不规范。
- **例外**：数学式内部允许半角（"(X+Y)≤min(5, 你的体力上限)"〖幸宠〗）与蓄力刻度"（4/4）"。
- **注意**：不要在中文里混入半角逗号、半角空格；全角斜杠"／"只出现在个别旧文本，不使用。

#### 规则 B-05：分号与顿号分工

- **正例（顿号并列短词）**："“X”为当前体力值、已损失体力值、场上人数中的一个"（〖振锋〗势太史慈）
- **正例（分号分隔并列句/条目）**："1.摸两张牌；2.回复1点体力；3.获得1点护甲。"（〖筑墼〗势孙韶）
- **反例（构造）**："摸两张牌，回复1点体力"（独立效果间用逗号）
- **补充**：顿号只管并列短词；凡能独立成句的效果或分条条目，一律用分号或句号分隔。

#### 规则 B-06：冒号引出列举

- **正例**："你选择**一项**：1.摸两张牌；2.回复1点体力；3.获得1点护甲。"（〖筑墼〗势孙韶）
- **反例**："选择一项：1：摸两张牌"（〖妙略〗势董昭，编号后再用冒号）
- **补充**："选择一项：""依次""以下/如下"后接冒号是官方列举的固定引出方式；编号本身不再用冒号。

### 2.3 固定术语对照表（非规范 → 规范）

| 非规范写法 | 规范写法 | 规则 |
|---|---|---|
| 丢弃 / 弃掉 | **弃置** | B-07 |
| 抽两张牌 | **摸两张牌** | B-07 |
| 使其 / 让其 | **令其** | B-07 |
| 如果 | **若** | B-07 |
| 把一张牌 | **将一张牌** | B-07 |
| 随后 | **然后** | B-07 |
| 得到一张牌 | **获得**（"因摸牌而得到的牌数""以此法得到"等衍生搭配保留） | B-08 |
| 恢复1点体力 | **回复**1点体力（恢复仅用于**装备栏**，反义"废除"；**复原**用于武将牌） | B-08 |
| 直至 | **直到** | B-08 |
| 视为 / 当做 / 当作 | 按句式分工：**视为**=结果转化（"视为使用一张【杀】"）；**当作/当做=带来源牌**（"将一张X牌当作Y使用"），"当作"更正式 | B-08 |
| 移去 / 移除 | 按标记类型分工：**数量型标记→移除（推荐）**，移去亦可；**牌类标记（如"田"）→弃置** | B-08 |
| 亮出手牌 | **展示**手牌（亮出=牌堆顶/底的翻面过程；展示=手牌区） | B-08 |
| 展示牌堆顶 | **亮出**牌堆顶 | B-08 |
| 一位角色 | **一名角色** | B-03 |

#### 规则 B-12

"**你可以选择**"表示选择动作可以发生（可选）；"**你选择**"表示技能一旦发动**必须**执行选择动作。二者语义不同，不能混用。

- **正例（可选）**："有角色受到非属性伤害后，你可选择一项执行后移除：1.横置或重置至多两名角色；…"（〖燃缕〗崔芷，"可/可以"均可）
- **正例（强制）**："②准备阶段，你选择一项，并于结束阶段执行另一项：…"（〖弘毅〗势陈到）

### 2.4 句式与语序

#### 规则 B-09：时机 → 条件 → 代价 → 效果

描述先给时机（标签/阶段/"当…时"），再给"若"条件，最后给效果。

- **正例**："**当你令一名角色进入濒死状态时**，**若**本轮已有角色死亡，**你将势力变更为群**，然后…"（〖迂难〗势钟会）
- **正例（结论接"则"）**："若当前回合角色因此失去了牌，**则**本轮此技能失效。"（〖道转〗势于吉）
- **反例（构造）**："你可以摸两张牌，当你受到伤害后"（时机后置）
- **补充**：条件一律用"若"，"则"可省可接。

#### 规则 B-10：频率限制置于句首，用固定句式

- **正例**："**出牌阶段限一次**，你可消耗任意蓄力点…"（〖肆恣〗势钟会）
- **正例**："**每回合限一次**，你可以将你或者当前回合角色…"（〖道转〗势于吉）
- **反例（构造）**："此技能每回合只能使用一次"

频率句式样例：

- 出牌阶段限一/两/三次
- 每回合限一/两/三次
- 每轮限一/两次
- 每回合每名角色限一次

#### 规则 B-11：指代用"其"

已指明的角色用"其"；需要重申或避免长距离歧义时用"该角色"。

- **正例**："若**其**手牌数小于等于你，你跳过摸牌阶段"（〖探锋〗势夏侯尚）
- **反例（构造）**："该武将""这位角色""他"

## 三、进阶规范

### 3.1 括号的类型与用法

#### 规则 A-01：牌名用【】

- **正例**："弃置任意张【桃】、【酒】、【顺手牵羊】、【五谷丰登】、坐骑牌"（〖制肴〗刘盼兮）
- **反例（构造）**："弃置两张杀"

#### 规则 A-02：技能名用〖〗

适用于所有技能名引用，含〖看破①〗〖急御①〗等序号形态。

- **正例**："然后获得〖克昌〗，若已有则改为升级〖克昌〗"（〖迂难〗势钟会）
- **正例**："你重置〖急御①〗"（〖急御〗势娄圭）
- **反例（构造）**："获得技能克昌"（无括号）
- **补充**：技能名引用必须括号化。"获得〖X〗"与"获得技能〖X〗"均可，**推荐省略"技能"二字**。

#### 规则 A-03：补充说明放句末括号

（）内按用途分类：

| 用途 | 例（出处） |
|---|---|
| 变量定义 | （X为本次变化的值）〖挟志〗势钟会 |
| 条件补充 | （你的回合开始时，这些效果失效）〖肆恣〗势钟会 |
| 数量限定 | （你至多拥有6个“烈”标记）〖战烈〗势太史慈 |
| 修饰限制 | （无距离限制）〖清蹈〗势国渊 |
| 蓄力刻度 | （4/4）〖肆恣〗势钟会 |

- **反例**："(X+Y)≤min(5, 你的体力上限)"中混用全半角括号（〖幸宠〗滕公主——数学式内半角可接受，但括号本身须成对同形）

### 3.2 变量的命名与定义

#### 规则 A-04：变量按用途命名，定义放句末括号

| 变量 | 用途 | 例（出处） |
|---|---|---|
| X、Y、Z | 数量变量，依序命名 | "你摸X张牌并展示Y张手牌"（〖幸宠〗滕公主） |
| A、B | **角色代号** | "你可以选择一名男性角色A和另一名其他角色B"（〖妩艳〗曹媛） |
| A—K | **牌点数** | "点数视为K"；"从A至K的所有整数"（〖割圆〗刘徽） |

定义句式："（X为…）"，置于变量所在句的句末。

- **正例**："然后获得其X张牌（X为游戏轮数且至多为3）"（〖结姻〗谋孙尚香）
- **反例 1（全角字母）**："Ｘ张牌"（〖执盟〗梦袁绍）
- **反例 2（构造）**："X是本次变化的值"（定义须用"X为"）

### 3.3 分条的格式与逻辑

#### 规则 A-05：分条按用途选编号，间隔符配套

| 适用场景 | 编号 | 条目间隔符 | 例 |
|---|---|---|---|
| 选择一项后的分条（默认） | **1. 2. 3.** | **分号** | "你选择一项：1.令其获得1点护甲；2.你将势力变更为吴…"（〖结姻〗谋孙尚香） |
| 多效果技能 | **①②③** | **句号** | "①你的登场势力为蜀。②游戏开始时，…"（〖结姻〗谋孙尚香） |

配套要求：

1. 列举前用引出词+冒号（B-06）："选择一项：""依次""以下/如下"；
2. ①条目内部的无编号并列短句用分号（"你获得2个「毅」标记；当你造成或受到伤害后，…；你至多拥有…"〖弘毅〗势陈到，原文量词"个"按 B-03 应改"枚"）；
3. 多效果技能的①②③之间用句号。

- **反例**："你可选择：1，若你的体力值大于你的手牌数，…"（〖膂力〗文鸯，"1，"式）
- **反例**："选择一项：1：摸两张牌"（〖妙略〗势董昭，编号后用冒号）

### 3.4 标签的位置与格式

#### 规则 A-06：标签置句首；单标签后接句号，多标签之间用逗号、最末标签后接句号

此规则与是否分条无关。

- **正例（单标签）**："锁定技。①游戏开始时，…"（〖弘毅〗势陈到）
- **正例（多标签）**："主公技，锁定技。群势力角色使用【杀】无距离限制…"（调整自〖克昌〗势钟会）
- **反例（旧写法）**："主公技、锁定技，群势力角色…"（顿号分隔；末标签后逗号，属不规范）

标签细则：

1. **标签术语**：锁定技、限定技、觉醒技、主公技、转换技、蓄力技、势力技、连招技、使命技；
2. **势力技带势力名前缀**："蜀/魏/群势力技。"（〖穷途〗承张郃·文件D："群势力技。每回合限一次。你可以将一张非基本牌置于武将牌上视为使用一张【无懈可击】。"）；
3. **蓄力技、连招技后接参数括号**："蓄力技（4/4）。""连招技（单目标牌+武器牌），…"（〖霸关〗威吕布）；
4. **多标签顺序**："主公技，锁定技。""蜀势力技，锁定技。""锁定技，转换技。"——主公技/势力技类在前，状态类在后；
5. 标签出现在句子中间的，几乎都是对标签的**引用罗列**（"无法获得限定技、觉醒技、主公技"〖相谶〗张裕），不是标签用法。

#### 规则 A-07：标记名加引号

- **正例**：“烈”（〖战烈〗势太史慈）；“田”“粮”“颂”（〖屯田〗等）
- **反例（构造）**："获得一个烈标记"（无引号）
- **注意**：引号方向必须正确（“开”闭），不可出现”烈”这类错向写法。

#### 规则 A-08：代价句用"若如此做"

先陈述可选动作，后以"若如此做"引出后续效果；"若"后可跟指代（"若其如此做""若目标角色如此做"）；未写主体默认"若你如此做"。

- **正例**："…令一名角色获得其中一种颜色的所有牌。**若如此做**：1.每阶段限一次，你再失去…"（〖润微〗势陆郁生）
- **正例**："…其他角色使用一张【杀】或普通锦囊牌，**若如此做**，此牌目标…"（〖倨傲〗新杀谋关羽）

## 四、综合改写案例（6 例，由易到难）

案例中"不规范原文"为构造（无语义变化）；"最终规范文本"为真实官方描述（逐字引用），或按已确认规则对官方文本做**最小调整**——每一处调整均在案例中注明。

### 案例 1（★ 标签与括号）：〖克昌〗势钟会

**不规范原文：**

> 主公技、锁定技。群势力角色使用【杀】无距离限制；你使用的杀不可被响应。

**逐步修改：**

1. "主公技、锁定技。" → "主公技，**锁定技。**"——多标签之间用逗号、最末标签后用句号（A-06）；
2. "你使用的杀" → "你使用的【**杀**】"——牌名加【】（A-01）。

**最终规范文本**（仅第 1 处按 A-06 调整——原文"锁定技"后为逗号）：

> 主公技，锁定技。群势力角色使用【杀】无距离限制；你使用的【杀】不可被响应。

### 案例 2（★★ 标点与变量）：〖挟志〗势钟会

**不规范原文：**

> 锁定技 当你的体力值变化后 你获得x点蓄力点（X是本次变化的值） 如果你有因此未获得的蓄力点 你的手牌上限与使用【杀】的次数永久+1

**逐步修改：**

1. "锁定技 当你…" → "锁定技。当你…"——单标签后用句号（A-06）；
2. 全文补全逗号、句号，句号收尾（B-04）；
3. "x点" → "**X**点"——变量用大写半角 X（A-04）；
4. "（X**是**本次变化的值）" → "（X**为**…）"——定义句式（A-04）；
5. "**如果**你有" → "**若**你有"（B-07）。

**最终规范文本**（仅第 1 处按 A-06 调整——原文"锁定技"后为逗号）：

> 锁定技。当你的体力值变化后，你获得X点蓄力点（X为本次变化的值）。若你有因此未获得的蓄力点，你的手牌上限与使用【杀】的次数上限永久+1。

### 案例 3（★★★ 分条与标记）：〖挥锐〗威马腾

**不规范原文：**

> 出牌阶段开始或受到伤害后，你可选择一项发动：⒈获得两个骑；⒉移动场上任意一个骑至任意其他角色处；⒊你视为使用一张【杀】。

**逐步修改：**

1. "⒈/⒉/⒊" → "**1./2./3.**"——选择一项后的分条默认用"1."，⒈已停用（A-05）；
2. "两个骑/任意一个骑" → "两**枚**“骑”/任意一**枚**“骑”"——标记计数用枚（B-03）、标记名加引号（A-07）；


**最终规范文本**（按 A-05、B-03 调整——原文用"1、…；…。"与"两个/一个"）：

> 出牌阶段开始或受到伤害后，你可选择一项发动：1.获得两枚“骑”；2.移动场上任意一枚“骑”至任意其他角色处；3.你视为使用一张【杀】。

### 案例 4（★★★★ 锁定技分条与嵌套）：〖弘毅〗势陈到

**不规范原文：**

> 锁定技，①游戏开始时你获得两个『毅』标记，当你造成或受到伤害后你获得一个『毅』标记，你至多拥有四个『毅』标记。②准备阶段，你选择一项并于结束阶段执行另一项：一、摸X张牌（X是你当前拥有的『毅』标记数）；二、移去全部『毅』标记。

**逐步修改：**

1. "锁定技，①" → "锁定技。①"——单标签后句号（A-06）；
2. ①内部的"你获得两个『毅』标记，当你…" → "你获得…标记；当你…"——①条目内并列短句用分号（A-05）；
3. "『毅』" → "**「毅」**"——标记引号用“”,『』不用（A-07）；
4. "两个/一个/四个『毅』" → "2枚/1枚/4枚「毅」"——标记计数用枚（B-03）；
5. "一、/二、" → "**1./2.**"——②内选择一项后的分条用"1."（A-05）；

**最终规范文本**（真实官方；调整说明：原文为"2个/1个/4个「毅」"，按 B-03 改量词为"枚"）：

> 锁定技。①游戏开始时，你获得2枚「毅」标记；当你造成或受到伤害后，你获得1枚「毅」标记；你至多拥有4枚「毅」标记。②准备阶段，你选择一项，并于结束阶段执行另一项：1.摸X张牌（X为你当前拥有的「毅」标记数）；2.移除所有「毅」标记。

### 案例 5（★★★★★ 双变量与数学式）：〖幸宠〗滕公主

**不规范原文：**

> 每轮开始的时候，你可以声明2个自然数X和Y，(X+Y)≤min(5、你的体力上限)。你摸X张牌并亮出Y张手牌。若如此做的话，当你于本轮内失去一张以此法展示的牌后，你摸两张牌。

**逐步修改：**

1. "每轮开始**的时候**" → "每轮**开始时**"——时机表述用"开始时"（B-09）；"2个" → "**两个**"（B-01）；
2. "min(5、你的体力上限)" → "min(5, 你的体力上限)"——数学式内用半角逗号（B-04 例外）；
3. "**亮出**Y张手牌" → "**展示**Y张手牌"——亮出限牌堆顶/底，手牌区用展示（B-08）；
4. "若如此做**的话**" → "若如此做"（A-08）。

**最终规范文本**：

> 每轮开始时，你可声明两个自然数X和Y，且(X+Y)≤min(5, 你的体力上限)。你摸X张牌并展示Y张手牌。若如此做，当你于本轮内失去一张以此法展示的牌后，你摸两张牌。

（注：官方原文"你可声明"，构造原文为"你可以声明"——两种情态均保留，见 B-12。）

### 案例 6（★★★★★ 使命技与多效果分条）：〖结姻〗谋孙尚香（节选）

**不规范原文：**

> ③“结姻”角色的出牌阶段开始时，你必须选择一项：①令其获得一点护甲。②你将势力变更为吴，然后获得其X张牌，X是游戏轮数且至多为3。

**逐步修改：**

1. "你**必须**选择一项" → "你**选择**一项"——无"可以"的"你选择"本身就表达发动后必须执行，不需写"必须"（B-12）；
2. "①/②" → "**1./2.**"——选择一项后的分条用"1."（A-05）；
3. "令其获得**一点**护甲" → "令其获得**1点**护甲"（B-02）；
4. 条目间的句号 → **分号**——"1."式条目间隔符（A-05）；
5. "，X是游戏轮数且至多为3" → "（X为游戏轮数且至多为3）"——变量定义移入句末括号并用"X为"（A-03/A-04）。

**最终规范文本**（真实官方节选，逐字一致）：

> ③“结姻”角色死亡后，你减少1点体力上限；“结姻”角色的出牌阶段开始时，你选择一项：1.令其获得1点护甲；2.你将势力变更为吴，然后获得其X张牌（X为游戏轮数且至多为3）。

## 六、改写检查清单（按顺序自检）

1. **字符层**：有无半角标点混入中文（B-04）？有无全角字母（A-04）？以句号收尾了吗（B-04）？
2. **标签**：标签在句首吗（A-06）？单标签接句号/多标签逗号+末句号了吗（A-06）？势力技带势力名前缀了吗（A-06）？蓄力技带（X/X）刻度了吗（A-03）？
3. **数字与量词**：计数用汉字（B-01）？点值用阿拉伯数字（B-02）？量词搭配对（B-03）？标记用"枚"（B-03）？
4. **术语**：逐项过第五节对照表（B-07/B-08）——弃置/令/若/将/然后/摸；获得/回复-恢复-复原/直到/以此法；视为与当作分工；移除按标记类型；亮出与展示分工。
5. **句式**：时机→条件→效果（B-09）？频率句式置句首（B-10）？"你可以选择/你选择"用对了吗（B-12）？指代用"其"（B-11）？
6. **括号**：牌名【】（A-01）？技能名〖〗（A-02）？补充说明在句末括号（A-03）？
7. **变量**：X/Y/A/B/K 用对用途了吗（A-04）？定义"（X为…）"齐全吗（A-04）？
8. **分条**：选择一项后的分条用"1."、多效果技能才用①②③（A-05）？引出词+冒号（B-06）？①间句号、"1."间分号（A-05）？
9. **标记**：标记名为引号（“”，A-07）？引号方向正确？
10. **连接**：代价句用"若如此做"了吗（A-08）？主体默认"你"，需要时"若其如此做"（A-08）？
11. **终检**：逐句对照原意——规范化只改形式，**不改语义**。
